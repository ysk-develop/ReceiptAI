    このアプリについて

    レシート写真またはテキストメモを Gemini API で解析し、店舗名・日付・品目・金額・カテゴリを抽出します。画面上で誤読を修正してから、Google Apps Script 経由で Google ドライブへ JSON を送信できます。

    APIキーと GAS URL は各端末の localStorage にのみ保存されます。

    解析結果は参考です。金額・カテゴリは保存前に必ず確認してください。
